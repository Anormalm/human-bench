Before you begin / 开始前

  1. Read the situation, relationship and facts. Judge which response you would use in that situation.
    先读情境、关系和事实，判断哪条回复在这个场景更适用。
  2. A tie is valid when neither response has a meaningful advantage, including when both need work.
    两条没有明显优劣时可以选平局，包括两条都需要修改的情况。
  3. Assess each response separately: send as is, revise, or reject and rewrite.
    分别判断每条回复：原样发送、修改后使用，或不用并重写。
  4. Work independently. Use the given context; do not look up candidate identities or ask another model to decide.
    请独立判断，依据给定情境，不查询来源，也不让其他模型代答。
